# World Developer 1.0.0

Install current World documentation, coding workflows, and Developer Portal operations in Codex from the Developer Portal repository.

- Three focused skills with guides for World ID, Mini Apps, World Chain, and World agents.
- Optional team authentication and protected local signing-key handoff.
- Schema-checked support for synthetic staging test verifications when available on the server, with fallback for older deployments.
- Versioned installation, automated package checks, and a standalone release archive.

Requires Codex plugin support, Node.js 20+, and macOS/Linux for private local storage. Python 3 is used for optional interactive credential setup. See the package README for installation and the validation report for tested behavior and limitations.
